1 좌표 단위 = 1 mm

공간 크기

좌표계는 X=가로(폭), Y=세로(길이), Z=높이입니다. 내부 계산값은 mm 그대로 사용합니다.

기본 구조 배치

확정/실측 기준: 외부 900×2000mm, 내부 폭 860mm, 전체 높이 250mm, 하부 여유 약 210mm. 20×40 각관 방향은 치수 관계로 추정한 값이며, 가로바·힌지 여유·다리 상세 위치는 아직 임시입니다.

표시 / 스냅

예: 그리드는 100mm 간격으로 보여도 좌표값 1은 실제 1mm입니다.

직육면체 부품 추가

위치는 부품의 왼쪽·앞·아래 모서리를 기준으로 입력합니다.

STL 불러오기

불러온 STL은 모델 원래 치수를 mm로 취급합니다. 불러온 뒤 중앙 바닥에 배치됩니다.
